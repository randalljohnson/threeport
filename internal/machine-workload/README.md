# internal/machine-workload

This package contains the generated and custom code for the machine workload
controller.  The reconcilers in this package manage workloads deployed to
machine runtimes by running shell scripts over SSH.  Each definition supplies
a create script (required), an optional update script, and a delete script
(required); the controller invokes the matching script over the existing SSH
connection on create, update, and delete events.

Scripts run with an optional working directory and timeout.  Environment
variables come from the workload instance's `Env` field when set, falling
back to the definition's `Env` when the instance value is nil.  `Env` is a
list of `KEY=VALUE` entries (matching `os/exec.Cmd.Env` and Docker container
env conventions) stored as JSONB.  Each entry's value is encrypted at rest;
the keys remain queryable in the column.

Some of the code in these packages is generated by `threeport-sdk`.  Any
file with the `_gen.go` suffix should not be edited directly - it will be
overwritten by subsequent code generation.
