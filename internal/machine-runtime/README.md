# internal/machine-runtime

This package contains the generated and custom code for the machine runtime
controller.  The reconcilers in this package manage SSH-reachable machines
(VMs, bare-metal hosts, edge devices) that serve as runtimes for machine
workloads.  Reconciliation includes capturing the remote host key on first
connect when one is not supplied and verifying reachability.

SSH credentials on the machine runtime instance (`SSHKey`, `SSHPassword`) are
stored encrypted at rest.

Some of the code in these packages is generated by `threeport-sdk`.  Any
file with the `_gen.go` suffix should not be edited directly - it will be
overwritten by subsequent code generation.
